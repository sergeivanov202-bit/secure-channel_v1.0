РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
СПО "Защищённый канал" (Клиент + Сервер политики)

1. УСТАНОВКА
   Windows: распакуйте архив, убедитесь в наличии wintun.dll.
   Linux: sudo apt install python3-pip && pip install -r requirements.txt

2. БЫСТРЫЙ СТАРТ (демо без TUN)
   • Снимите галочку TUN в настройках клиента.
   • Нажмите «Подключиться».

3. ПОЛНЫЙ РЕЖИМ (TUN / VPN)
   • Запустите сервер → «Запустить сервер».
   • Запустите клиент от администратора с включённым TUN.

4. ГЕНЕРАЦИЯ СЕРТИФИКАТОВ
   Кнопка «Создать тестовые сертификаты» в GUI.
   ВНИМАНИЕ: Для продакшена используйте корпоративный PKI!

5. УСТРАНЕНИЕ НЕПОЛАДОК
   Permission denied /dev/net/tun → sudo mknod /dev/net/tun c 10 200
   Certificate verify failed → проверьте даты сертификатов и NTP.
   Доступ запрещён → настройте политики CPU/AV на сервере.

6. ГОРЯЧИЕ КЛАВИШИ
   Ctrl+C — аварийная остановка (консоль).
   Кнопка «Отключиться» — корректное завершение.
